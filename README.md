# Major Share (전공 자산 선순환 네트워크)

**대학생 전용 전공 서적 및 실험 기자재 매매/대여 통합 플랫폼**

본 프로젝트는 대학 캠퍼스 내에서 유휴 자산인 전공 서적과 실험 기구들을 효율적으로 순환시키기 위해 설계된 안드로이드 애플리케이션입니다. 설계서(@docs)의 객체지향 분석 및 설계(OOA/D) 원칙을 충실히 반영하여 구현되었습니다.

## ✨ 핵심 기능 (Key Features)

### 1. 매매 및 대여 통합 시스템
- 전공 자산의 소유권 이전(매매)과 일시적 사용권 공유(대여)를 모두 지원합니다.
- 대여 시 물품별 최대 대여 가능 기간(`max_rent_days`) 설정을 지원합니다.

### 2. 정교한 예약 및 자동 승계 (Auto-Succession)
- **Reservation Queue**: 대여 중인 물품에 대해 최대 3명까지 예약 대기가 가능합니다.
- **자동 승계**: 기존 대여자가 물품을 반납하는 즉시, 예약 1순위 사용자에게 대여 권한이 자동으로 이전되며 실시간 알림이 발송됩니다.

### 3. 독점 방지 및 연장 제어 (Block Extension)
- 예약 대기자가 존재할 경우, 자원 독점 방지를 위해 기존 대여자의 기간 연장 신청을 시스템 수준에서 차단합니다.
- 대여 연장은 거래당 최대 1회로 제한하여 선순환 구조를 보장합니다.

### 4. 신뢰 기반 매너 시스템 및 자동 패널티
- 거래 종료 후 상호 평가를 통해 매너 점수(`Manner Score`)를 관리합니다.
- **자동 패널티**: 반납 기한 초과 시 연체 일수에 비례하여 시스템이 자동으로 매너 점수를 감점 처리합니다.

### 5. 실시간 소통 및 알림
- **채팅**: 거래 당사자 간 1:1 채팅을 지원하며, 텍스트뿐만 아니라 이미지 전송 기능과 읽음 확인('1' 표시) 기능을 포함합니다.
- **푸시 알림**: 거래 신청, 승인, 물품 전달, 반납 요청 및 채팅 수신 시 실시간으로 시스템 알림을 발송합니다.

### 6. 강력한 관리자(Admin) 모니터링
- 시스템 전체 통계(유저 수, 거래 수 등) 요약 정보를 제공합니다.
- 불량 유저 제재(일시 정지/영구 정지) 및 부적절 게시글 삭제 권한을 가집니다.
- 부정 거래 방지를 위해 모든 거래의 채팅 로그를 실시간으로 모니터링할 수 있습니다.

## 🔒 보안 (Security)
- 모든 사용자의 비밀번호는 **SHA-256** 해싱 알고리즘을 통해 암호화되어 안전하게 저장됩니다.

## 🛠 테스트 가이드 (Testing Guide)

### 관리자(Admin) 계정 테스트 방법
본 과제의 핵심인 '관리자에 의한 시스템 제어' 시나리오 검증을 위해 특정 아이디 패턴에 관리자 권한을 부여하는 정책을 적용했습니다.
- **방법**: 회원가입 시 아이디를 **`admin`**으로 시작하게 생성하십시오. (예: `admin123`, `administrator`)
- **결과**: 해당 계정으로 로그인 시 메인 화면 하단에 **[관리자 대시보드]** 버튼이 활성화됩니다.
